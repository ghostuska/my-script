# Лабораторная работа №1. Сбор параметров операционной системы

*Описание работы

Программа определяет тип операционной системы, в которой она была запущена (поддерживаются Windows, MacOS и Linux), собирает технические параметры окружения и экспортирует итоговую структуру данных в файл формата JSON.

*Перечень собираемых параметров
Скрипт собирает сбалансированный набор системных метрик без избыточности:

* Общие параметры:
  * Тип_OS — семейство операционной системы (Windows, MacOS, Linux).
  * Архитектура_процессора — архитектура процессора (например, AMD64, x86_64, arm64).
  * Логические_ядра_ЦП — количество доступных логических ядер процессора.
* **Специфичные параметры (в блоке Детальная_информация):**
Для Windows:s:** Главная (мажорная) версия ОС и номер сборки.
Для MacOS:S:** Кортеж с информацией о версии macOS.
Для Linux:x:** Название дистрибутива, полученное из системного файла /etc/os-release.

## Обоснование используемых модулей
В соответствии с ограничениями задания, сбор данных реализоисключительно с помощью стандартных модулей Pythonon** (без вызова внешних утилит командной строки ОС):
1. platform — используется для кроссплатформенного определения типа ОС, архитектуры процессора и версии мака.
2. os — применяется для подсчета ядер процессора и безопасной проверки существования файлов конфигурации в Linux.
3. sys — используется для извлечения низкоуровневых параметров сборки в среде Windows.
4. json — стандартное средство для структурирования и сохранения итогового словаря в файл конфигурации.

Привлечение сторонних библиотек (из PyPI) не потребовалось, так как стандартная экосистема Python полностью решает поставленные задачи.

## Инструкция по запуску
1. Склонируйте репозиторий или скачайте файл скрипта.
2. Запустите скрипт через терминал:
  
   python my_script.py
   
3. После завершения работы в корневой директории будет создан файл os_info.json.
